# 與AI共舞 — 萬能的小幫手

> 寫給有 10 年前端經驗、剛重返職場的你

## 課程簡介

這門課專為前端工程師量身打造，目標是**快速銜接 AI 工具在現代工作流程中的位置**。你不需要從頭學習 AI 原理，你只需要知道它能幫你做什麼、怎麼用最順手。

休養兩年，不代表你落後了——你有扎實的工程底子，這門課讓你用最短的時間，接住 AI 這波浪。

## 主要工具

- **Claude Code** (主體) — Anthropic 出品的 AI coding agent
- **Gemini** (輔助) — Google 的 AI，示範多模型協作
- **VSCode** — 主要開發環境
- **ai-skills-hub MCP** — 自建 skill 共用平台

## 學習目標

完成此課程後，你將能夠：

1. 理解 AI Agent 的運作方式與限制
2. 熟練使用 Claude Code 在 VSCode 中開發專案
3. 建立自己的 Skill 工具庫
4. 透過 MCP 擴展 Agent 的能力
5. 用 AI 完成從需求分析到 Code Review 的完整開發週期
